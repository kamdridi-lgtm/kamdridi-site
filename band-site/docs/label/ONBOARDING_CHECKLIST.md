# KAMDRIDI RECORDS Artist Onboarding Checklist

Use this checklist after an artist has been selected for a package, release partnership, or label review. Work should not begin until the correct written agreement and required assets are in place.

- Contact Person:

## Agreement And Deal Setup

- [ ] Signed written agreement
- [ ] Package / deal type confirmed
- [ ] Scope of work confirmed
- [ ] Contract status confirmed
- [ ] Payment status if paid package
- [ ] Revenue split confirmed if partnership
- [ ] Approved costs confirmed if any

## Artist Information

- [ ] Artist contact info
- [ ] Bio
- [ ] Social links
- [ ] Distributor status

- [ ] Preferred public name spelling confirmed

## Music Assets

- [ ] Songs received
- [ ] WAV files

- [ ] Lyrics
- [ ] Song credits
- [ ] Split sheet
- [ ] Producer credits
- [ ] Featured artist approvals if applicable
- [ ] Sample or beat license information if applicable

## Visual Assets

- [ ] Cover art

- [ ] Logo if available

- [ ] Usage permissions confirmed

## Release Planning

- [ ] Release date target
- [ ] EPK needs

- [ ] Press or playlist targets
- [ ] Social content needs

## Final Approval Checklist

- [ ] Agreement complete
- [ ] Rights and splits confirmed
- [ ] Audio assets complete
- [ ] Visual assets complete
- [ ] Metadata complete
- [ ] Payment complete if applicable
