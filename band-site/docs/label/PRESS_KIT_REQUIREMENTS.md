# KAMDRIDI RECORDS Press Kit Requirements

Purpose: standard EPK requirements for every artist, project, or release.

## Core Artist Materials

- [ ] Short bio
- [ ] Long bio
- [ ] Artist photo
- [ ] Logo
- [ ] Approved images
- [ ] Website link
- [ ] Contact
- [ ] Social links

## Release Materials

- [ ] Cover art
- [ ] Release description
- [ ] Genre tags
- [ ] RIYL / sounds like
- [ ] Streaming links
- [ ] Release date
- [ ] Credits
- [ ] Lyrics if appropriate

## Press And Positioning

- [ ] Press quote placeholder
- [ ] One-sentence project description
- [ ] Short pitch paragraph
- [ ] Notable context, if true and useful
- [ ] No fake stats or unsupported claims

## Rights And Licensing

- [ ] Licensing contact
- [ ] Sync contact if different
- [ ] Master ownership status
- [ ] Publishing ownership status
- [ ] Clean/instrumental availability if relevant

## AI Disclosure

- [ ] AI disclosure only if needed
- [ ] Disclosure wording approved if needed
- [ ] No unnecessary public explanation

## Final Check

- [ ] Links work
- [ ] Images are high enough quality
- [ ] Public wording is approved
- [ ] Contact information is correct
- [ ] Artist name and release title are spelled correctly
