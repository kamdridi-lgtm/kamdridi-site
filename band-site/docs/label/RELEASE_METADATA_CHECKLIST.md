# KAMDRIDI RECORDS Release Metadata Checklist

Use this checklist before any release is uploaded to a distributor or announced publicly. Metadata mistakes can delay release dates and create rights problems.

## Release Identity

- [ ] Artist name
- [ ] Release title
- [ ] Song title
- [ ] Version title if any
- [ ] Genre
- [ ] Language
- [ ] Explicit / clean
- [ ] Featured artists confirmed

## Codes And Dates

- [ ] ISRC
- [ ] UPC
- [ ] Release date
- [ ] Pre-save date if available
- [ ] Time zone or market timing notes

## Credits And Ownership

- [ ] Songwriter credits
- [ ] Producer credits
- [ ] Performer credits
- [ ] Master owner
- [ ] Publishing owner
- [ ] Splits confirmed
- [ ] Split sheet stored
- [ ] Sample or beat license confirmed if applicable

## Assets And Approval

- [ ] Cover art approved
- [ ] Cover art meets distributor specs
- [ ] Lyrics final
- [ ] Audio WAV final
- [ ] Master approved
- [ ] Clean version received if needed
- [ ] Artist approval received

## Distribution And Post-Release

- [ ] Distributor uploaded
- [ ] Release preview checked
- [ ] Spotify/Apple/YouTube links after release
- [ ] EPK updated
- [ ] Website updated
- [ ] Promo copy ready
- [ ] Release added to catalog tracker
