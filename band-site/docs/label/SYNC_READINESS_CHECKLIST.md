# KAMDRIDI RECORDS Sync Readiness Checklist

Purpose: prepare KAMDRIDI RECORDS songs for sync and licensing review.

Sync buyers need songs that are discoverable, clearable, editable, and professionally delivered.

## Rights And Clearance

- [ ] Master ownership clear
- [ ] Publishing ownership clear
- [ ] Songwriter splits confirmed
- [ ] Producer splits confirmed if applicable
- [ ] No uncleared samples
- [ ] No legal conflicts
- [ ] Agreement status clear
- [ ] Clearance contact confirmed
- [ ] One-stop status marked yes/no/unknown

## Metadata

- [ ] ISRC available
- [ ] BPM/key
- [ ] Genre tags
- [ ] Mood tags
- [ ] Lyrical themes
- [ ] Language
- [ ] Explicit / clean status
- [ ] Short description

## Audio Assets

- [ ] High-res WAV
- [ ] Clean lyrics or clean version if needed
- [ ] Instrumental version
- [ ] Stems
- [ ] 30 sec edit possibility
- [ ] 60 sec edit possibility
- [ ] Master file location documented
- [ ] Instrumental file location documented

## Delivery Notes

- Track:
- Artist:
- Clearance contact:
- One-stop status:
- Known restrictions:
- Best-fit uses:
- Notes:

## Internal Rule

Do not pitch a song as sync-ready unless ownership, splits, clearance contact, and usable audio assets are confirmed.
